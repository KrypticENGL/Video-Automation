# API notes

One file per third-party service (`instagram.md`, `gemini.md`, `kling.md`, `r2.md`, `expo-push.md`), written **before** the integration code, per the `verify-external-api` skill.

Each file records: official doc URLs, date checked, endpoints and params used, auth, limits, prices, error codes and gotchas. If the code and these notes disagree, re-read the docs and fix both.
